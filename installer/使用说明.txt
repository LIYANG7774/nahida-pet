纳西妲桌宠 Nahida Pet v1.0.0
====================================

这是什么？
  一个常驻 Windows 桌面的纳西妲小桌宠。背景全透明、置顶显示，
  会呼吸浮动、眨眼、自己在桌面散步，也能被拖动、被摸头、被喂点心。

怎么玩？
  · 左键拖动 —— 拎起来，她会挣扎；松手落地会弹跳
  · 左键单击 —— 摸头（连戳 5 次有惊喜）
  · 滚轮上下 —— 调整她的大小
  · 右键菜单 —— 聊聊天 / 喂点心 / 逗她玩 / 讲故事 / 猜谜语 / AI 设置 / 退出

AI 聊天怎么开？
  右键 -> 「AI 设置」，选一个服务商（OpenAI / DeepSeek / Kimi / 智谱 /
  通义千问 / 硅基流动 / 本地 Ollama），把自己的 API Key 粘贴进去，
  点「测试连接」看到成功提示即可。不填 Key 也能玩，只是不能聊天。

她会记住什么？
  配置存在：%USERPROFILE%\.nahida_pet\config.json
  里面只有 AI 相关的设置和心情/饱食度状态，API Key 只留在你自己的电脑上，
  不会上传到任何地方。

卸载
  「设置 -> 应用 -> 已安装的应用」里找到「纳西妲桌宠」，或开始菜单里的卸载项。
  卸载时会问你要不要一并删掉配置文件，默认保留。

小提示
  · 长时间不理她，她会睡着（左上角冒 zzz）。
  · 心情和饱食度会慢慢下降，摸摸头、喂点心就能补回来。
  · 想让她开机自动出现，安装时勾选「开机自动启动」即可。
